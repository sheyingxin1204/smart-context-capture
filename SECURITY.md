# Security policy

Please do not report secrets or private user data in a public issue. Send a
private security report through the repository's GitHub security contact, or
open a minimal issue that contains no sensitive details and request private
follow-up.

The project is designed to use least privilege. Reports involving unintended
cookie, token, hidden-file, unrelated-tab, network, download, or write access
should include a minimal reproduction and the affected version.
